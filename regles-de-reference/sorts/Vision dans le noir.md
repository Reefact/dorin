# Vision dans le noir

**Référence : SRD français 5.2.1 — règles 2024.**

- **Niveau :** 2
- **École :** Transmutation
- **Classes :** Druide, Ensorceleur, Magicien, Rôdeur
- **Temps d’incantation :** action
- **Portée :** contact
- **Composantes :** V, S, M (une carotte séchée)
- **Durée :** 8 heures
- **Concentration :** Non
- **Rituel :** Non

## Effets — formulation officielle française

Pour toute la durée, une créature consentante que vous touchez physiquement acquiert la Vision dans le noir sur 45 m.
