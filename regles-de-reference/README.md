# Règles de référence

Ce répertoire concerne **D&D 2024 exclusivement** et est indépendant du personnage Dorin.

## Sources et comparaison

- [SRD officiel 5.2.1 français](https://media.dndbeyond.com/compendium-images/srd/5.2/FR_SRD_CC_v5.2.1.pdf) : source primaire, descriptions et règles de 339 sorts.
- [AideDD — sorts de 2024](https://www.aidedd.org/spell/fr/) : catalogue de 391 sorts et fiches individuelles.
- [Donjon-Dragon — compendium 2024](https://dnd.ratscorporation.com/compendium/sorts) : point de contrôle supplémentaire.
- [Index structuré des 391 noms](https://github.com/lucas-martinati/shard-dnd-fr/blob/main/outputs/catalogue-aidedd-2024.json) : rapprochement des intitulés.
- [Extraction française du SRD officiel](https://github.com/Itus19/CreaDonjon/blob/master/data/srd/fr-source/srd-5.2.1-fr.txt) : remise en forme des textes librement publiés.
- [Relevé communautaire du Manuel des joueurs 2024](https://github.com/Antoine-C-Hubert/merzhin-spellbook/blob/main/spells_to_add.txt) : données partielles à contrôler.

## Convention

- Une fiche `Nom du sort.md` contient sa description officielle en français dans le SRD 5.2.1.
- Une fiche `Nom du sort - à vérifier.md` manque de description complète, le sort n’étant pas inclus dans le SRD.
- Les variantes de traduction et de nom ne sont pas des divergences de règles.
- Les écarts documentés face au SRD sont automatiquement tranchés au profit de l’officiel.
- Les autres compendiums n’ont pas encore été contrôlés intégralement, fiche par fiche ; aucune prétention d’exhaustivité de cette comparaison.
